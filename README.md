# Introduction to the Dart Language Through Examples

> ⚠️ **This repository is not a software project.** There is no application to install, no package to publish, nor any code issues to fix: this is **course material**, written for students learning the Dart language.

## 🎯 Who is this course for?

This course is intended for students who have **no prior knowledge** of the Dart language.
It is designed on the same principle as the course *Introduction to the TypeScript Language and
the NestJS Framework*: learning a language through a series of small, standalone scripts,
commented line by line, rather than through a theoretical explanation of its grammar. The course’s structure follows that of the step-by-step TypeScript course, with a Dart script alongside each TypeScript script, to allow for a direct comparison of how the two languages address the same need.

## 📚 Course Outline

The course is organized into major sections:

1. **Setting Up the Development Environment** — verifying tools, setting up the VS Code project, first script, static analysis, linter, and the Dart extension.
2. **Dart Fundamentals** — language basics, arrays, objects,
   strings, regular expressions, functions, errors and
   exceptions, modules, event-driven programming and asynchronous functions,
   classes, and new features in Dart 3.x (records, patterns, sealed classes).
3. **Installing a NestJS Server** — the income tax calculation server,
   taken directly from the TypeScript course: it serves as a real-world target for testing Dart’s HTTP functions,
   just as it serves as a target for the HTTP clients in the original course. (The chapters that teach NestJS itself are intentionally omitted here: this is a
   topic not directly related to learning the Dart language.)
4. **Dart’s HTTP functions and clients for the tax calculation service** — four
   client variants for the same server: a simple CLI script, separate DAO/business logic layers,
   a compiled project, and finally a full web application with an HTML interface.
5. **Database Access** — the native MySQL driver, followed by a “lightweight ORM” written by hand, since there is no mature equivalent of TypeORM or Prisma for Dart.
